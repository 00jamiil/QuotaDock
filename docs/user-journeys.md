# QuotaDock v1 user journeys

1. As a developer with personal AI subscriptions, I can see clearly labelled remaining quota and reset times without opening each provider.
2. As an API organization owner, I can enter an admin key once and see month-to-date token usage and spend without the key entering app storage or logs.
3. As an Alibaba Token Plan user, I can opt into an isolated official-console sign-in and see normalized credit usage without using the inference key for automation.
4. As a user working through an outage, I continue to see the last good value, its age, and an honest health state rather than a fabricated zero.
5. As a privacy-conscious user, I can disconnect a provider or clear all local data and leave no QuotaDock-managed secrets behind.
6. As a keyboard or assistive-technology user, I can operate every widget and settings action through stable native UI Automation elements.
